Why did GitHub Pages show "404 File Not Found"?

Because Apex QMS is a native Android mobile application built with Kotlin and Jetpack Compose, the repository only contained the Android source code (.kt, Gradle build scripts, and resource XMLs).

This index.html now serves as the official Apex QMS Web Portal & APK Distribution Hub so your GitHub Pages deployment works immediately without showing a 404!

Core Android Modules

Apex QMS consists of four specialized operational views optimized for industrial handhelds and plant terminals:

1. Fleet Telemetry Monitor

Live bird's-eye view of all extrusion, rotogravure, and slitting lines with real-time sensor updates, throughput gauges, and one-tap quarantine triggers.

2. Roll Audit & Sign-off

Inspection checklists verifying ASTM D882 tensile yield, ASTM D1922 tear resistance, corona treat dynes, and barcode lot verification.

3. Defect & NCR Log

Comprehensive Non-Conformance Reporting with root cause analysis (5-Why), containment actions, scrap footage calculations, and severity tagging.

4. Lab Test Records

Historical quality logs, coefficient of friction (COF) records, dart drop impact metrics, and batch certificates of analysis (CoA).

How to Run & Deploy Apex QMS

Choose one of the methods below to run or test the native Android application:

1

In Google AI Studio (Instant Emulator)

You can run and interact with the full native Android app directly in your browser using the streaming Android emulator in AI Studio's right panel.

2

In Android Studio (Development & Testing)

Clone the GitHub repository to your local machine and open it in Android Studio:

git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

Select an Android Virtual Device (AVD) or plug in an Android phone via USB, then press Run (Shift + F10).

3

Build Android APK via Command Line

Build a ready-to-install debug APK using Gradle on Linux, macOS, or Windows:

# On Linux / macOS:
./gradlew assembleDebug

# On Windows:
gradlew.bat assembleDebug

The generated APK will be at: app/build/outputs/apk/debug/app-debug.apk. You can install it on any Android device via ADB:

adb install app/build/outputs/apk/debug/app-debug.apk
4

Automated GitHub Actions CI/CD (Optional)

This repository includes a GitHub Action workflow (.github/workflows/build-apk.yml) that automatically builds the APK whenever you push to GitHub, attaches the compiled .apk as a downloadable artifact, and deploys this web hub to GitHub Pages.
